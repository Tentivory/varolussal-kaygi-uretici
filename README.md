# VAROLUŞSAL KAYGI ÜRETİCİSİ v1.0

## Bu Ne?

Bu, insanlık tarihinin en önemli yazılım projesidir. Her saniye size varoluşun anlamsızlığını, hayatın geçici olduğunu ve çayın bitmek üzere olduğunu hatırlatan bir Python scriptidir.

**Neden var?** Çünkü biri sormalıydı. Ve o biri bendim. Hayır, sen değilsin. Ben.

## Nasıl Çalışır?

```bash
python kaygi.py
```

Script sonsuz döngüde rastgele felsefi kaygılar üretir. Her biri öncekisinden daha derin ve daha anlamsızdır.

## Özellikler

- %100 organik, GDO'suz kaygı üretimi
- Çay molasında kullanıma uygun
- CPU'nuzu yormaz çünkü zaten hayat yoruyor
- Sonsuz ölçeklenebilir (ta ki siz bitene kadar)

## Uyarı

Bu scripti çalıştırdıktan sonra hayata bakış açınız değişebilir. Değişmezse de sorun değil, zaten hiçbir şey değişmiyor.
